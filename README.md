# 🥗 AI Diet Planner

An AI-based web application that provides personalized calorie recommendations and meal plans based on user information and fitness goals.

## 🚀 Features

- Personalized calorie recommendation
- BMI, BMR and activity-based calculations
- Weight loss, weight maintenance and weight gain goals
- Vegetarian and non-vegetarian food preferences
- Personalized meal recommendations
- Simple and responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS

## 📋 User Inputs

The application takes the following inputs:

- Age
- Height
- Weight
- Activity Level
- Fitness Goal
- Food Preference
